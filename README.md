# Needle in the Ocean (หาเข็มในมหาสมุทร)

เกมแนว 3D สำรวจใต้ทะเลลึก ควบคุมโดรนดำน้ำเพื่อค้นหา "เข็ม" ขนาดจิ๋วที่ซุ่มซ่อนอยู่ตามพื้นทรายก่อนที่ออกซิเจนจะหมดลง

## 🎮 วิธีการเล่น (How to Play)

1. เปิด Browser แล้วไปที่: **http://localhost:5173/** (หรือดับเบิ้ลคลิกเปิดไฟล์ `index.html` โดยตรง)
2. **การควบคุม**:
   - **W, A, S, D** หรือ **แป้นลูกศร**: บังคับทิศทางโดรนดำน้ำ
   - **Shift**: เร่งความเร็วเทอร์โบบูสต์ (Turbo Boost)
   - **M**: สลับโหมดใช้เมาส์นำทาง (Mouse Follow Mode)
   - **Spacebar** หรือ **คลิกซ้าย**: สแกน & เก็บกู้เข็ม (Scan & Grab)
   - **ปุ่ม AUDIO**: เปิด/ปิดเสียงสังเคราะห์
   - **ปุ่ม PAUSE**: หยุดเกมชั่วคราว

## 🌟 ระบบหลักในเกม
- **Dynamic Lighting & Deep Fog**: ความมืดมิดใต้สมุทรพร้อมไฟฉายสปอตไลท์ส่องลงสู่พื้นทราย
- **Sonar Distance & Dynamic Ping**: เสียงโซนาร์สังเคราะห์จะดังและถี่ขึ้นเรื่อยๆ ตามระยะห่าง Euclidean จริง
- **Metallic Sparkle**: ประกายแสงวิบวับสะท้อนขึ้นมาเมื่อส่องไฟโดนเข็ม
- **Difficulty Scaling**:
  - ด่าน 1+: แผนที่ขยายใหญ่ขึ้น, รัศมีไฟแคบลง, อัตราการลดของออกซิเจนเร็วขึ้น
  - สิ่งลวงตา (Decoys): ตะปู ตะขอ กระป๋อง ขยะทะเล ส่งสัญญาณโซนาร์รบกวน
  - กระแสน้ำใต้ทะเล (Ocean Currents): มีเวกเตอร์กระแสน้ำพัดต้านและเปลี่ยนทิศทางในด่าน 3+
- **Penalty System**: กดสแกนพลาด/กดโดนสิ่งลวงตา เสียพลังงาน 15%!
